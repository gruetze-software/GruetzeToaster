# GruetzeToaster 1.1.0

New original propeller toasters, isometric toast and flying floppy disks, with optional recognizable
C64 and Amiga-style computers. The C64 blinks its red light and the Amiga slides a disk into its side drive.
Enabled computers are guaranteed to appear when the object count allows it, while remaining rare companions.

- A shared scene renderer, small shared textures and continuous animations reduce rendering work and allocations.
- Settings and About have an English interface, updated Grütze-Software computer branding, Avalonia version and Ko-fi links.
- Updated to .NET 10 LTS and Avalonia 12.1.4, with tests on Windows, Linux and macOS.
- Native Wayland selection and an explicit X11 fallback option. Snap/Flatpak templates are included for future work, without store releases.
- Updated documentation with a current application screenshot and installation/startup instructions for each platform.

## Downloads

All application packages include the .NET runtime. Keep all extracted files together.

- **Windows x64:** ZIP with Settings/About/Windowed/Fullscreen launchers and a `.scr` executable.
- **Linux x64 and ARM64:** TAR.GZ and DEB packages for glibc-based desktops.
- **macOS Apple Silicon:** `macos-arm64.zip`; **Intel:** `macos-x64.zip`. Extract and drag `GruetzeToaster.app` into Applications.
- The PNG screenshot and icon are also available separately. Verify downloads against `SHA256SUMS.txt`.

macOS bundles declare macOS 14 or later as the minimum and are ad-hoc signed, without Developer ID or notarization.
If a trusted download is blocked on first launch, use System Settings → Privacy & Security → Open Anyway after attempting to open it.
For settings, close the running instance and run `open -a /Applications/GruetzeToaster.app --args --settings`.

On Linux and macOS this is a standalone application, without automatic idle activation, session locking or a native macOS `.saver` extension.
Interactive testing on actual Linux desktops and Intel/Apple Silicon Macs is still needed.
See the [README for installation and known limits](https://github.com/gruetze-software/GruetzeToaster/blob/v1.1.0/README.md).
