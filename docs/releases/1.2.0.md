# GruetzeToaster 1.2.0

- New propeller-toaster app icon, also used in Settings and About.
- Show or hide each object type independently. All six types are enabled by default; existing choices are preserved.
- Optional small background stars, drawn as one cached batch. With every object type disabled, the animation loop pauses.
- More compact Settings dialog and a shorter README with installation instructions for Windows, Linux and macOS.
- Grütze-Software links now open [www.gruetze-software.de](https://www.gruetze-software.de).
- [Bugs and feature requests](https://github.com/gruetze-software/GruetzeToaster/issues) have a dedicated link in About.

## Packages

All downloads include the .NET runtime. Keep extracted files together.

- Windows x64: ZIP with launchers and Windows screensaver executable.
- Linux x64 / ARM64: DEB and TAR.GZ packages for glibc-based desktops.
- macOS Apple Silicon / Intel: separate ZIP files containing `GruetzeToaster.app`.

macOS bundles declare macOS 14 or later as the minimum and are ad-hoc signed, without Apple notarization.
Drag the app into Applications. For settings, close the running app and use
`open -a /Applications/GruetzeToaster.app --args --settings`.
Linux and macOS run as standalone apps, without automatic idle activation or session locking.
